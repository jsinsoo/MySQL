#001기초SELECT

첫 SELECT

상세 설명

테이블 없이도 SELECT로 문자열을 출력할 수 있습니다. AS는 결과 열의 별칭입니다.

예상 결과: Hello, MySQL!
OneCompiler에 복사하여 실행
SELECT 'Hello, MySQL!' AS message;
#002기초SELECT

숫자 계산

상세 설명

SELECT 안에서 산술 연산을 수행할 수 있습니다. 쉼표로 여러 계산 결과를 한 행에 표시합니다.

예상 결과: 30 / 200 / 5
OneCompiler에 복사하여 실행
SELECT 10+20 AS sum_value, 10*20 AS product_value, 20/4 AS quotient_value;
#003기초함수

CONCAT 문자열 결합

상세 설명

CONCAT()은 여러 문자열을 순서대로 이어 붙입니다.

예상 결과: MySQL / 안녕 데이터베이스
OneCompiler에 복사하여 실행
SELECT CONCAT('My','SQL') AS word, CONCAT('안녕',' ','데이터베이스') AS greeting;
#004기초함수

대소문자 변환

상세 설명

UPPER()는 대문자, LOWER()는 소문자로 바꿉니다.

예상 결과: MYSQL / database
OneCompiler에 복사하여 실행
SELECT UPPER('mysql') AS upper_text, LOWER('DATABASE') AS lower_text;
#005기초함수

문자열 길이

상세 설명

CHAR_LENGTH()는 문자 수를, LENGTH()는 바이트 수를 반환합니다. 한글에서는 두 개념의 차이를 관찰하기 좋습니다.

OneCompiler에 복사하여 실행
SELECT CHAR_LENGTH('데이터베이스') AS chars, LENGTH('MySQL') AS bytes;
#006기초함수

ROUND CEIL FLOOR

상세 설명

ROUND()는 반올림, CEIL()은 올림, FLOOR()는 내림입니다.

예상 결과: 3.14 / 4 / 3
OneCompiler에 복사하여 실행
SELECT ROUND(3.141592,2) AS r, CEIL(3.14) AS c, FLOOR(3.99) AS f;
#007기초연산자

나머지 MOD

상세 설명

MOD(a,b)와 %는 모두 나머지를 구합니다.

예상 결과: 2 / 2
OneCompiler에 복사하여 실행
SELECT MOD(17,5) AS r1, 17 % 5 AS r2;
#008기초날짜

현재 날짜와 시간

상세 설명

CURDATE(), CURTIME(), NOW()를 이용해 실행 시점의 날짜와 시간을 확인합니다.

학습 포인트: 실행할 때마다 값이 달라질 수 있습니다.
OneCompiler에 복사하여 실행
SELECT CURDATE() AS today, CURTIME() AS current_time, NOW() AS current_datetime;
#009기초조건

IF 조건식

상세 설명

IF(조건, 참값, 거짓값)는 간단한 조건 분기를 표현합니다.

예상 결과: PASS
OneCompiler에 복사하여 실행
SELECT IF(85>=60,'PASS','FAIL') AS result;
#010기초조건

CASE 다중 조건

상세 설명

CASE는 여러 WHEN 조건을 위에서부터 검사해 첫 번째 참인 결과를 반환합니다.

예상 결과: A
OneCompiler에 복사하여 실행
SELECT CASE WHEN 92>=90 THEN 'A' WHEN 92>=80 THEN 'B' ELSE 'C' END AS grade;

#012기초INSERT

한 행 INSERT

상세 설명

INSERT INTO ... VALUES로 한 행을 삽입합니다. 열 이름을 명시하면 값의 의미가 분명합니다.

#015기초DDL

#017기초DDL

상세 설명

OneCompiler에 복사하여 실행

#018기초DDL

CHECK 제약조건

상세 설명

CHECK는 허용할 값의 조건을 테이블 정의에 포함합니다. 여기서는 점수를 0~100으로 제한합니다.

OneCompiler에 복사하여 실행
DROP TABLE IF EXISTS student; CREATE TABLE student(id INT PRIMARY KEY,name VARCHAR(20),score INT CHECK(score BETWEEN 0 AND 100)); INSERT INTO student VALUES(1,'홍길동',95); SELECT * FROM student;
#019기초DDL

상세 설명

DESC 또는 DESCRIBE는 열 이름, 자료형, NULL 허용 여부, 키 정보를 보여 줍니다.

OneCompiler에 복사하여 실행
DROP TABLE IF EXISTS student; CREATE TABLE student(id INT PRIMARY KEY,name VARCHAR(20),score INT); DESC student;

#100고급재귀 CTE

재귀 CTE 조직도

상세 설명

루트에서 시작해 manager_id 관계를 따라 자식 노드를 반복 탐색합니다. 트리 구조를 SQL로 학습하기 좋은 예입니다.

OneCompiler에 복사하여 실행
DROP TABLE IF EXISTS employee_tree; CREATE TABLE employee_tree(id INT PRIMARY KEY,name VARCHAR(20),manager_id INT); INSERT INTO employee_tree VALUES(1,'대표',NULL),(2,'개발팀장',1),(3,'연구팀장',1),(4,'개발자A',2),(5,'개발자B',2); WITH RECURSIVE org AS(SELECT id,name,manager_id,0 AS depth FROM employee_tree WHERE manager_id IS NULL UNION ALL SELECT e.id,e.name,e.manager_id,org.depth+1 FROM employee_tree e JOIN org ON e.manager_id=org.id) SELECT * FROM org ORDER BY depth,id;
