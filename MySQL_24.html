1. 성취기준과 학습 목표

성취기준

트랜잭션의 의미와 ACID 특성을 이해하고 여러 데이터 변경 작업을 하나의 논리적 단위로 처리할 수 있다.

START TRANSACTION, COMMIT, ROLLBACK, SAVEPOINT를 활용하여 변경을 확정·취소·부분 복구하고 자동 커밋과 격리 수준의 의미를 설명할 수 있다.

학습 목표

  1. 트랜잭션과 ACID의 기본 의미를 설명한다.
  2. COMMIT과 ROLLBACK의 차이를 구분한다.
  3. SAVEPOINT를 이용해 부분 복구를 수행한다.
  4. 자동 커밋과 격리 수준이 트랜잭션에 미치는 영향을 이해한다.

3. 수업 시작 이야기

📚 인문학자의 이야기 — 약속은 끝까지 지켜질 때 의미가 있다

사람 사이의 약속은 시작했다는 사실보다 끝까지 책임졌는지가 중요합니다. 한쪽만 지켜지고 다른 쪽은 무너진 약속은 신뢰를 만들지 못합니다.

트랜잭션도 여러 작업을 하나의 약속으로 묶습니다. 출금과 입금처럼 함께 완성되어야 하는 일은 전부 성공하거나 전부 취소되어야 합니다.

🏛 철학자의 이야기 — 선택에는 확정과 철회의 순간이 있다

철학은 인간의 선택과 책임을 오래 탐구해 왔습니다. 생각 중인 결정과 세상에 확정한 결정은 다릅니다.

COMMIT은 결정을 확정하는 순간이고, ROLLBACK은 아직 확정하지 않은 선택을 되돌리는 용기입니다. 중요한 것은 실수를 숨기는 것이 아니라 확정 전에 검토하는 태도입니다.

🔬 과학자의 이야기 — 실험은 재현 가능하고 복구 가능해야 한다

과학자는 실험 절차를 단계별로 기록합니다. 중간 결과가 잘못되면 전체 실험을 버리거나 특정 단계로 돌아가 다시 시작합니다.

SAVEPOINT는 실험 노트의 중간 지점과 같습니다. 트랜잭션 전체를 포기하지 않고 필요한 부분만 복구하게 합니다.

➗ 수학자의 이야기 — 등식의 양변은 함께 보존되어야 한다

수학에서 등식의 한쪽만 바꾸면 균형이 무너집니다. 같은 연산을 양변에 적용해야 관계가 유지됩니다.

계좌 이체도 한 계좌의 감소와 다른 계좌의 증가가 함께 일어나야 전체 합이 보존됩니다. 트랜잭션은 데이터 세계의 균형을 지키는 장치입니다.

교사의 시작 이야기

오늘 배우는 트랜잭션은 단순한 명령어 묶음이 아닙니다. 중요한 일을 서두르지 않고, 중간에 검토하며, 잘못되면 되돌리고, 확실할 때만 책임 있게 확정하는 사고방식입니다. 데이터베이스는 실수를 하지 않는 사람을 기대하지 않습니다. 대신 실수가 전체 시스템을 무너뜨리지 않도록 안전한 절차를 제공합니다.

UPDATE accounts
SET balance = balance - 50000
WHERE account_id = 1;

06

SAVEPOINT까지 부분 취소

주문 입력만 취소하고 재고 변경은 유지한 뒤 COMMIT하는 예입니다. ROLLBACK TO는 지정한 SAVEPOINT 이후의 변경만 되돌립니다.

UPDATE products
SET stock = stock - 1
WHERE product_id = 10;

VALUES (3, 10);

ROLLBACK TO step1;

6. 수업 끝 이야기

🌙 시인의 이야기 — 퇴고는 문장의 ROLLBACK이다

시인은 첫 문장을 바로 COMMIT하지 않습니다. 지우고 고치고 다시 읽으며 가장 오래 남을 말을 선택합니다. 다만 마감 직전까지 ROLLBACK만 하면 시집은 빈 파일이 될 수 있습니다.

📖 소설가의 이야기 — 한 장면의 변화가 결말과 일관되어야 한다

주인공이 첫 장에서 떠났는데 마지막 장에서 설명 없이 교실에 앉아 있다면 독자는 혼란스럽습니다. 트랜잭션은 이야기의 앞뒤가 모순되지 않도록 지키는 편집자입니다.

🎭 희곡인의 이야기 — 막이 오르면 약속된 장면이 완성되어야 한다

배우 한 명은 비극을 연기하고 다른 배우는 갑자기 요리 방송을 시작하면 무대의 일관성이 무너집니다. COMMIT은 모두가 같은 장면에 도착했을 때 내려지는 결정입니다.

🎬 연극인의 이야기 — 리허설에는 되돌아갈 권리가 있다

리허설에서 실수했다고 공연 인생 전체를 삭제하지 않습니다. SAVEPOINT로 돌아가 장면을 다시 맞춥니다. 인생에도 가끔 중간 저장이 있었으면 좋겠지만, 간식 시간은 자동 COMMIT되는 편입니다.

🎼 음악인의 이야기 — 합주는 모든 파트가 함께 끝나야 한다

피아노는 끝났는데 바이올린이 아직 두 페이지 남았다면 곡은 완성되지 않습니다. 트랜잭션도 모든 작업이 함께 성공해야 아름답게 마무리됩니다.

오늘의 오래 남는 마지막 이야기

우리는 실수하면 모든 것이 끝났다고 생각하기 쉽습니다. 그러나 확정되지 않은 실패는 배움의 과정이며, 되돌아가 다시 선택할 수 있는 순간이 남아 있습니다.

인생에는 완벽한 자동 커밋보다 신중한 트랜잭션이 필요합니다. 중요한 결정 앞에서는 잠시 멈추고, 잘못된 길에서는 ROLLBACK하고, 작은 성취에는 SAVEPOINT를 남기십시오. 그리고 충분히 고민한 꿈은 용기 있게 COMMIT하십시오. 여러분의 오늘이 흔들려도 삶 전체의 일관성은 다시 만들 수 있습니다.
