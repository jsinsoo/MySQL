3. 수업 시작 이야기

📚 인문학자의 이야기 — 연결은 서로 다른 세계를 이해하게 한다

인문학은 문학, 역사, 철학처럼 서로 다른 분야를 이어 인간을 더 넓게 이해하게 합니다. 하나의 지식만으로는 보이지 않던 의미가 연결을 통해 드러납니다.

오늘 파이썬과 MySQL도 서로 다른 세계에서 출발하지만 연결되는 순간 데이터를 저장하고 분석하며 활용하는 하나의 시스템이 됩니다.

🏛 철학자의 이야기 — 관계는 존재의 범위를 넓힌다

철학자는 어떤 존재가 혼자 있을 때와 다른 존재와 관계를 맺을 때 어떻게 달라지는지 묻습니다. 파이썬은 계산과 흐름 제어에 강하고, MySQL은 데이터를 구조적으로 보관하는 데 강합니다.

둘의 연결은 각자의 한계를 줄이고 가능성을 넓히는 협력의 철학입니다.

🔬 과학자의 이야기 — 관측 장치와 기록 장치는 함께 있어야 한다

센서가 아무리 정확해도 측정값을 저장하지 않으면 변화의 의미를 분석할 수 없습니다. 반대로 저장 공간만 있고 관측 장치가 없다면 새로운 데이터가 들어오지 않습니다.

파이썬은 데이터를 수집하고 처리하는 관측 장치가 되고, MySQL은 그 결과를 오래 보관하는 기록 장치가 됩니다.

➗ 수학자의 이야기 — 입력과 출력 사이의 통로가 계산을 완성한다

수학의 함수는 입력을 받아 규칙에 따라 출력을 만듭니다. 데이터베이스 연결도 프로그램의 요청을 SQL로 전달하고 결과를 다시 프로그램으로 돌려주는 통로입니다.

연결 객체와 커서는 이 통로의 방향과 순서를 관리합니다.

교사의 시작 이야기

지금까지 우리는 MySQL 안에서 SQL을 작성했습니다. 오늘부터는 파이썬 프로그램이 데이터베이스에게 질문하고 대답을 받게 됩니다. 처음 연결이 성공해 “MySQL 연결 성공”이라는 짧은 문장이 출력되는 순간은 작아 보이지만, 여러분의 프로그램이 실제 데이터 시스템으로 확장되는 중요한 출발점입니다. 연결은 단순한 기술이 아니라 서로 다른 도구가 함께 일하도록 만드는 설계입니다.

딕셔너리 커서 활용

dict_cursor = connection.cursor(dictionary=True)

dict_cursor.execute('''
SELECT student_id,
       student_name,
       grade
FROM students
LIMIT 5
''')

    print(row["student_name"], row["grade"])

09

예외 처리를 포함한 연결

연결 과정에서 발생할 수 있는 오류를 try-except로 처리합니다. 오류 내용을 출력하면 비밀번호, 서버 상태, 데이터베이스 이름 문제를 확인하는 데 도움이 됩니다.

import mysql.connector
from mysql.connector import Error

connection = None

try:
    connection = mysql.connector.connect(
        host="localhost",
        user="root",
        password="비밀번호",
        database="school_db"
    )

    if connection.is_connected():
        print("MySQL 연결 성공")

except Error as error:
    print("연결 오류:", error)

finally:
    if cursor is not None:
        cursor.close()

        connection.close()

6. 수업 끝 이야기

🌙 시인의 이야기 — 한 줄의 다리가 두 세계를 잇는다

시는 짧은 한 줄로 먼 기억과 현재의 마음을 이어 줍니다. 데이터베이스 연결 코드도 몇 줄뿐이지만 파이썬과 MySQL이라는 두 세계를 연결합니다. 단, 비밀번호를 시처럼 공개적으로 낭송하면 보안 선생님이 운율과 상관없이 등장합니다.

📖 소설가의 이야기 — 좋은 인물은 혼자 성장하지 않는다

소설 속 인물은 다른 사람과 만나고 갈등하고 협력하며 성장합니다. 프로그램도 여러 기술과 연결될 때 더 큰 문제를 해결할 수 있습니다.

🎭 희곡인의 이야기 — 대화는 질문과 응답으로 이루어진다

희곡은 한 사람이 말하고 다른 사람이 응답하며 장면이 진행됩니다. cursor.execute()는 질문을 보내고 fetchone()과 fetchall()은 응답을 받는 데이터베이스의 대화법입니다.

🎬 연극인의 이야기 — 무대 뒤 연결이 끊기면 장면도 멈춘다

조명, 음향, 배우의 움직임은 보이지 않는 신호로 연결됩니다. 데이터베이스 연결도 눈에 잘 보이지 않지만 프로그램 전체를 움직입니다. 연결을 닫지 않으면 배우들이 퇴근했는데 조명만 밤새 켜진 셈입니다.

🎼 음악인의 이야기 — 다른 악기가 연결될 때 합주가 된다

피아노와 바이올린은 서로 다른 소리를 내지만 같은 박자와 악보를 공유하면 음악이 됩니다. 파이썬과 MySQL도 연결 정보와 SQL이라는 공통 언어를 통해 하나의 프로그램을 연주합니다.

오늘의 오래 남는 마지막 이야기

혼자 잘하는 능력도 중요하지만, 서로 다른 사람과 도구를 연결해 함께 결과를 만드는 능력은 더 큰 가능성을 엽니다. 연결은 자신을 잃는 것이 아니라 자신의 강점을 더 넓은 곳에 쓰는 방법입니다.

여러분도 앞으로 새로운 분야를 만날 때 “나는 이것을 모른다”에서 멈추지 말고 “내가 아는 것과 어떻게 연결할 수 있을까?”라고 질문하십시오. 오늘 파이썬과 MySQL이 연결된 것처럼 작은 배움들이 이어지면 어느 날 여러분만의 큰 시스템과 꿈이 만들어질 것입니다.
